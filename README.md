# Agent Gatekeeper (Amazon.in)
Python 3 only, no installs.
- `python run_tests.py` runs the test cases and writes TEST_RESULTS.md
- `python app.py` starts the web page at http://localhost:8000 (register, revoke, send requests, see audit log)
Set your number in `ENROLMENT_NO` in gatekeeper.py. Rules are in RULES.md.
